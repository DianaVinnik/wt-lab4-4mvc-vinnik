
# Система управления банковскими счетами

Лабораторная работа №4.
Разработка веб-приложения на ASP.NET Core MVC.

## Описание проекта

Веб-приложение предназначено для управления
банковскими счетами.

Основные возможности:
- Просмотр списка банковских счетов.
- Просмотр подробной информации о счёте.
- Добавление нового банковского счёта.
- Редактирование существующего счёта.
- Проверка правильности введённых данных.

## Используемые технологии

- C#
- ASP.NET Core MVC
- .NET 9
- Razor
- Bootstrap
- HTML и CSS
- Git и GitHub
- Docker

## Запуск приложения

1. Скачать проект.
2. Открыть папку проекта в VS Code.
3. Выполнить команду:

   dotnet run

4. Открыть локальный адрес из терминала в браузере.

## Публикация

Для публикации подготовлен Dockerfile.

Платформа размещения: Render.
